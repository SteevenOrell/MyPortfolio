My portfolio app using react.js, Tailwind, Primereact,Framer motion, Email.js

Author: Steeven Orell WEMIN

https://steeven-wemin-portfolio.vercel.app/

## Running locally

1. Copy `.env.example` to `.env` and fill in your EmailJS values.
2. `npm install`
3. `npm run dev` (or `npm start`) to start the dev server at http://localhost:3000
4. `npm run build` to build the production site into `build/`

Security headers (Content-Security-Policy, HSTS, etc.) are set in `vercel.json`.
